# Front End - Senior

## Definition
Diseña la arquitectura de la aplicación (microfrontends, monorepos), implementa estrategias de caché y rendimiento (Core Web Vitals), define estándares de seguridad (XSS, CSP) y lidera la creación de sistemas de diseño reutilizables.

## Specific Project
Sistema de diseño corporativo (Storybook) con microfrontends (Module Federation) que integra 3 equipos (checkout, catálogo, perfil) y estrategia de carga offline (PWA).

## Core Concepts
Module Federation (Webpack 5), Service Workers (Workbox), Core Web Vitals (LCP, FID, CLS), estrategias de caché (Cache-First, Network-First), AST para reglas de linting personalizadas, Chromatic / Percy para pruebas visuales, CSR vs SSR vs SSG.

## Recommended Modern Technologies
Turbopack, Remix / React Router 7, Module Federation 2.0, Astro (islas parciales), OWL (optimización Core Web Vitals), Playwright (E2E visual), OpenTelemetry (RUM).
