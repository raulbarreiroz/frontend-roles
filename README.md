# Front End - Junior

## Definition
Transforma diseños en interfaces funcionales usando HTML, CSS y JavaScript nativo o frameworks básicos (React/Vue). Consume APIs REST para mostrar datos y maneja eventos de usuario.

## Specific Project
App de lista de tareas (To-Do) con categorías, persistencia en localStorage y consumo de una API pública (ej. clima o frases célebres) para mostrar un dato adicional.

## Core Concepts
fetch/axios, Promesas y async/await, useState y useEffect, props y lifting state, eventos sintéticos, CSS Flexbox/Grid, diseño responsive (media queries), localStorage.getItem/setItem.

## Recommended Modern Technologies
Vite, React 19 o Next.js 15 (App Router básico), Tailwind CSS 4, shadcn/ui, React Hook Form + Zod, TanStack Query.
