# Front End - Semi Senior

## Definition
Gestiona el estado global de la aplicación (Redux/Zustand), optimiza el renderizado, aplica accesibilidad (WCAG) y maneja la integración compleja con backends (autenticación, paginación).

## Specific Project
Dashboard analítico con gráficos dinámicos (Chart.js), filtros avanzados (búsqueda, rango de fechas), paginación infinita y gestión de estado global para un carrito de compras o perfil de usuario autenticado.

## Core Concepts
Redux/Zustand (stores, slices, thunks), React Query / TanStack Query (caché, stale-while-revalidate), useMemo/useCallback/React.memo, rutas protegidas (React Router v6), debounce y throttle, Webpack/Vite (alias y variables de entorno).

## Recommended Modern Technologies
Next.js 15 (Server Actions, Streaming SSR), Zustand o Jotai, tRPC, Framer Motion, Vitest + Testing Library, Storybook 8.
