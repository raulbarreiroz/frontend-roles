# Atlas Design System + federation sketch

Tres shells (checkout / catalog / profile) comparten tokens y componentes del design system.
Hay un SW mínimo para offline y un stub de Module Federation.

```bash
cd atlas-ds
npm i
npm run storybook   # si instalas storybook después
npm run preview:sw  # sirve dist + SW
```

Esto es arquitectura de referencia: los remotes están simulados en `remotes/`.
